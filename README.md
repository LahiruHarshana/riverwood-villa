# riverwood-villa

## Project Structure

- `app/` - Next.js App Router pages, layouts, route handlers, and route-scoped styles.
- `components/` - Shared React components, grouped by feature such as `admin` and `ui`.
- `hooks/` - Reusable client hooks for auth, rooms, and bookings.
- `lib/` - Firebase, Cloudinary, messaging, auth, and Firestore data access utilities.
- `public/` - Static brand and villa imagery served directly by Next.js.
- `middleware.ts` - Route protection and request middleware.
